# 流光灯铺

一款无需联网素材、无需安装运行时依赖的浏览器三消游戏。目标目录为独立新项目，不会读取或修改 D:\AnLi 中的其他游戏。

## 运行环境

- Node.js 18 或更新版本
- 现代浏览器（Chrome、Edge、Firefox 或 Safari）

游戏逻辑、关卡、界面图形、品牌 SVG 图标、合成音效、纸面纹理和字体都在本地项目中，运行时不访问 CDN。浏览器标签图标和安装清单引用 `assets/brand-mark.svg` 与 `manifest.webmanifest`。显示用 Noto Serif SC 字形子集按 SIL Open Font License 1.1 随附于 `assets/fonts/`；版权与完整许可见该目录的 `OFL.txt`。

页面使用深蓝夜色、暖金色重点和冷蓝层次背景，配色集中在 `night.css`；背景由 CSS 绘制，沿用原有花窗与品牌 SVG，不使用 AI 生成图片。`styles.css` 管理页面布局、棋盘、动物棋子与消除效果。生产构建会同时打包这两层样式。

## 小动物棋子

五种棋子现为本地 SVG 绘制的圆润卡通头像：金黄色猫咪、薄荷绿兔子、杏橙色狐狸、浅蓝色企鹅、淡紫色小熊。猫耳、长兔耳、狐狸尖脸、企鹅蛋形脸和小熊圆耳提供颜色之外的轮廓区分。`src/pieces.js` 统一提供头像、中文名称和消除光色，棋盘、收集目标、图例、引导与读屏标签使用同一套定义；无需额外下载或图像依赖。

特殊棋子保留动物头像：横／纵箭头丝带代表光束，圆形星章代表灯芯晶石，虹彩菱形章代表透镜。冰霜、藤纹和锁链覆盖效果继续使用原有规则。存档中的五种棋子标识保持不变，已有关卡和奖励恢复后会直接显示新头像。开发服务器的 `/tests/animals-preview.html` 提供动物和特殊标记、覆盖层检查页，不修改存档，不进入生产构建。

## 开发启动

    npm run dev

浏览器打开 http://127.0.0.1:4173。开发服务器会直接提供项目文件，并支持修改后刷新。

## 生产构建与启动

    npm run build
    npm start

生产文件生成在 dist/，默认仍从 http://127.0.0.1:4173 提供。

## 验证

    npm test
    npm run build

验证脚本检查 36 关的内容约束、初始棋盘、可用操作和核心消除规则。游玩存档保存在浏览器 localStorage；可在设置中查看恢复说明并重置游戏。

开发时可以在独立端口启动服务器，打开 `/tests/effects-preview.html` 验证消除画面。此页提供普通匹配、连续级联、无效交换、四连/T 形/五连成形、横纵光束、晶石、透镜、六种双特效组合及障碍清理的固定局面，并可切换简化动画和降低闪光。它会写入当前端口的测试存档，因此请使用与正式游玩不同的端口（例如 PowerShell 中执行 `$env:PORT='4176'; npm run dev`）。测试页不会包含在生产构建中。

消除表现由 `src/effects.js` 读取逻辑层给出的清除范围、特效来源和掉落路径进行绘制。普通消除有碎片、光圈和当次得分；特殊棋子显示实际作用方向与范围。暂停、设置弹窗和切页会同时冻结动画与结算，简化动画保留短暂的范围和状态提示。

达到全部关卡目标后进入“余步化光”：每剩 1 步随机将场内 1 个棋子转成光束玻璃、灯芯晶石或虹彩透镜。光点从步数牌逐颗飞向落点，原玻璃随后显现特殊纹样；全部转化完成后短暂提示再自动引爆、连续掉落消除。降低闪光时省去飞行拖尾，简化动画时用短暂交叠显现代替飞行。可以暂停奖励、跳过奖励动画，或直接返回地图，完整奖励都会结算一次。主线奖励过程中刷新页面后，点击“继续修复”会从已保存的奖励起点恢复，得到相同的随机转化与最终分数。

## 评星规则

必须完成全部关卡目标才能过关；三星按包含余步化光奖励的最终总分评定，不再按剩余步数比例评定。一星为通关，二星达到本关二星分数线，三星达到本关三星分数线。36 关及夜灯小试的分数线固定在 `src/levels.js` 的 `starScores` 中，不随随机棋盘变化。关卡顶部常驻三星目标、差距和进度；暂停与结算界面显示完整的一至三星规则，结算时显示三星达标或还差多少分。第 1 关三星线为 10,000 分、二星线为 6,000 分；其他关卡按各自界面标注。历史最高星级、最高分和已解锁进度保留，重玩只更新更好的成绩。星级与修复材料均在余步奖励结算后计算。

消除测试页还提供达标奖励、奖励恢复和第 36 关结局局面，可设置达标后余步，检查 0 步、1 步或大量余步的结算。`npm test` 同时验证 36 关三星可达的解法、逐步转化后引爆、奖励分数计入星级、分数线边界、刷新结果一致和重复调用保护。

## 操作

- 点击图块，再点击相邻图块；也可以鼠标或手指拖动。
- 方向键移动焦点，Enter 或空格选择并交换。
- 雾霜（冰块）、藤纹或锁链覆盖的棋子不能主动交换，也不能被相邻棋子换入；特殊棋子同样受限。覆盖可通过原位匹配或特效清除，雾霜还可通过相邻消除清理，解除全部覆盖后即可交换。被拒绝的交换不耗步，提示功能只标出允许交换的位置。
- Esc 暂停，R 重新开始。
- 地图中的“夜灯小试”是固定布局的限步挑战。

## 三端适配与手机方向

手机推荐竖屏：8×8 方形棋盘在 390×844 视口下每格约 42 像素，横屏 844×390 下约 31 像素；竖屏更容易辨认动物、观察全盘和点击目标格。横屏继续支持游玩，使用左侧棋盘、右侧步数／目标／得分／三星进度的布局，不强制旋转或重新开局。

`src/layout.js` 按实际界面高度计算棋盘大小，包含换行的目标、常用按钮、安全区和浏览器可见高度。手机、平板常用按钮至少高 44 像素；紧凑布局收起棋子图例及重复操作说明，目标、得分、三星线和所有常用操作继续显示。地图和说明页面允许正常纵向滚动。旋转和窗口变化不会创建新棋盘，进行中的动画会按新尺寸重定位并保留暂停位置。

`src/input.js` 允许向相邻方向短划，不必准确滑过格子边界；取消指针和第二根手指不会错误触发交换。新手提示可从手机菜单的“操作提示”重新打开。

实际浏览器验证记录及截图见 [三端适配测试报告](docs/RESPONSIVE_TEST_REPORT.md)。独立开发端口的 `/tests/responsive-preview.html` 可选择 36 关和失败局面，`/tests/touch-preview.html` 可将合成触屏指针事件交给正式游戏处理器；两页均不进入生产构建。请使用独立端口 4176，避免覆盖正式端口的游玩存档。
